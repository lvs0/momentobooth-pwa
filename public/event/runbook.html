1. Pré-flight J−1 à J−3

Le but : vérifier que tout marche avant d'avoir 80 personnes devant la borne.

Matériel à prévoir

  • iPhone (ou Android) avec Safari/Chrome à jour, chargeur, batterie externe
  • Support/trépied pour la borne (vue à hauteur des visages)
  • Wi-Fi ou 4G stable sur le lieu (tester la 4G du lieu, pas celle de ta maison)
  • Un second téléphone pour servir de "guest test"

Checklist technique (à cocher)

  • Serveur lancé et joignable : curl -I http://TON_IP:8787/ renvoie 200 + les headers CSP
  • URL publique fonctionne depuis l'extérieur (tester depuis le second téléphone, en 4G)
  • Créer un event test : curl -X POST http://TON_IP:8787/api/guest/sessions -H 'Content-Type: application/json' -d '{}' → tu reçois token, hostKey, url
  • Ouvrir l'URL sur le second téléphone : la galerie s'affiche (vide OK)
  • Uploader une photo test depuis la borne, vérifier qu'elle apparaît sur le second téléphone en moins de 3 s
  • Activer l'aperçu caméra depuis la borne, vérifier qu'une image apparaît sur le second téléphone

Trouver ton IP publique locale

Si tu es sur le même Wi-Fi que ton téléphone, c'est l'IP LAN de ta machine :

ip -4 addr show | grep -oP 'inet \K[\d.]+' | grep -v 127.0.0.1

Si tu veux un accès depuis l'extérieur (réseau 4G des invités), il te faut un tunnel :

cloudflared tunnel --url http://localhost:8787

→ tu reçois une URL https://xxx.trycloudflare.com que tu donnes aux invités.

2. Jour J — installation de la borne 30 min avant

Installation physique

  1. Poser le trépied, fixer l'iPhone (orientation paysage ou portrait, au choix)
  2. Brancher le chargeur (une event de 4 h vide une batterie)
  3. Régler la luminosité au max, mode "ne pas déranger" activé
  4. Safari (ou PWA installée) → ouvrir l'URL de la borne

Préparer l'event (sur la borne)

  1. Appuyer longuement sur « Galerie » dans la barre du bas → ouvrir le panneau « Accès invités »
  2. Cliquer sur « Créer le QR + lien » → un QR apparaît + une URL + une clé hôte
  3. Copier la clé hôte dans un gestionnaire de mots de passe (ou la noter sur papier) — c'est elle qui te permet de publier/supprimer des photos pendant l'event, et d'exporter l'event à la fin
  4. Cliquer « Partager » pour envoyer le lien par message aux invités (ou imprimer le QR en A4)

Si tu actives « Aperçu caméra périodique », les invités voient une image de la caméra actualisée ~1×/s. Désactivé par défaut pour ne pas exposer la caméra sans consentement explicite.

Test minute zéro

  1. Prendre une photo test depuis la borne
  2. Vérifier qu'elle arrive dans la galerie de l'invité test
  3. Si OK : le bouton « ⚙︎ Test » du panneau affiche « ✓ Événement joignable, expire dans 7h59, 1 photo »

3. Pendant l'événement

Mode normal

  • Les invités scannent le QR, voient la galerie (lecture seule)
  • Tu shoot depuis la borne, les invités reçoivent la photo automatiquement
  • Tu peux activer l'aperçu caméra dans le panneau pour montrer un flux discret aux invités

Problème réseau

Si la borne perd le Wi-Fi :

  1. Vérifier le Wi-Fi (l'iPhone tombe sur la 4G en partage, mais ça sature vite)
  2. Si l'event est down > 5 min : créer un nouvel event, prévenir les invités qu'ils doivent rescanner
  3. Les sessions invitées survivent à un redémarrage du serveur (fichier photos/.sessions.json) — mais pas à un scale-to-zero serverless (Modal)

Suppression d'une photo inappropriée

Dans la galerie de la borne, ouvrir la photo → supprimer. La galerie de l'invité est mise à jour à la prochaine consultation (cache local, quelques secondes).

4. Après l'événement J+1

Exporter l'event

  1. Sur la borne, ouvrir le panneau « Accès invités »
  2. Cliquer « 📦 Exporter l'event » → un ZIP se télécharge avec toutes les photos + un manifest JSON + un lisez-moi
  3. Si tu as rechargé la borne : colle ta clé hôte dans le champ du panneau, puis clique « Exporter l'event »

Le ZIP contient : photos/*.jpg, momentobooth/manifest.json (empreinte SHA-256 de la clé hôte, dates, nombre), momentobooth/lisez-moi.txt.

Nettoyer

L'event expire tout seul après 8 h, mais les photos uploadées restent sur le disque.

Pour purger un event manuellement (et toutes ses photos) :

curl -X DELETE -H "x-guest-host-key: TA_CLE" http://localhost:8787/api/guest/TOKEN

Pour purger TOUT (attention, irréversible) :

rm ~/Projets/momentobooth-pwa/photos/*.jpg
rm ~/Projets/momentobooth-pwa/photos/.sessions.json
sudo systemctl restart momentobooth

5. Dépannage express

L'invité voit "Lien expiré ou introuvable"

Token invalide ou session expirée (8 h). L'invité doit rescanner le QR, ou l'hôte doit recréer un event.

La galerie de l'invité ne se met pas à jour

Cache côté navigateur. Tirer pour rafraîchir. Le serveur met Cache-Control: no-store sur la galerie, c'est Safari qui peut s'entêter.

"Trop d'uploads" (429)

Rate limit atteint : 60 photos / 5 min par IP sans event, 300 / 5 min avec un event. Attendre 5 min, ou réduire la cadence.

Le serveur ne démarre pas (systemd) 
sudo journalctl -u momentobooth -n 30 --no-pager

Cause typique : port 8787 déjà pris. sudo lsof -i :8787 pour voir qui.

Caméra ne s'active pas sur Safari iOS

HTTPS obligatoire pour la caméra. En local (http://localhost:8787) : Safari demande, mais en HTTP sur le réseau : non. Passez par un tunnel Cloudflare (voir §1).

La borne recharge l'onglet et la clé hôte est perdue

C'est normal, par design (sécurité) : la clé hôte n'est plus jamais persistée. L'hôte doit re-saisir sa clé dans le panneau « Accès invités » pour reprendre le contrôle (publier, supprimer, exporter). La clé a été affichée à la création avec un bouton « Copier ».

6. Limites connues

  • 8 h de TTL max par event. Au-delà, recréer un event.
  • ~300 photos / 5 min par IP (limite d'event). Au-delà, attente 5 min.
  • Pas de vidéo, seulement des photos + un aperçu JPEG périodique (1×/s).
  • Pas de comptes : la clé hôte est le seul secret. Si tu la perds, tu perds le contrôle de l'event.
  • Serveur serverless (Modal) : scale-to-zero invalide les sessions à froid. À éviter pour les events > 30 min sans trafic.
